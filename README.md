# 🎨 My Portfolio

A modern, responsive portfolio website showcasing my projects, skills, and experience as a developer.

## ✨ Features

- Clean and modern design
- Fully responsive (mobile, tablet, desktop)
- Project showcase with descriptions
- Skills section
- Contact information
- Smooth animations and transitions

## 🚀 Live Demo

Visit the live portfolio: [Portfolio Link](https://shorajgoat.github.io/portfolio/)

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```
portfolio/
├── index.html          # Main page
├── css/               # Stylesheets
├── js/                # JavaScript files
└── assets/            # Images and media
```

## 🛠️ Getting Started

### Clone the repository
```bash
git clone https://github.com/shorajgoat/portfolio.git
cd portfolio
```

### Open in browser
Simply open `index.html` in your web browser.

## 📝 Customization

- Edit `index.html` to update content
- Modify `css/` files for styling
- Update `js/` files for interactive features
- Replace images in `assets/` folder
